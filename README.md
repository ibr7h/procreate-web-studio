# Procreate Web Studio (PWA) 🎨✒️
### أستوديو الخط العربي ومحاكي الرسم التفاعلي وميزان السطور

تطبيق ويب تقدمي (**Progressive Web App - PWA**) متطور يحاكي بيئة رسم **Procreate** الاحترافية، مخصص ومطور لفنون الخط العربي والرسم الرقمي مع ميزان السطور، إمكانية التثبيت كتطبيق مستقل والعمل بالكامل دون اتصال بالإنترنت (**Offline**).

---

## 🌟 أبرز المميزات (Features)

1. **واجهة Procreate الزجاجية الاحترافية (Glassmorphism UI):**
   - أشرطة التمرير العمودية للتحكم الفوري في الحجم (Size) والشفافية (Opacity).
   - دوال التراجع والإعادة وسجل الحركات (Undo / Redo History).
   - عجلة الألوان المتطورة ولوحات الحفظ.

2. **أستوديو الفُرش وقطة القلم (Calligraphy & Brush Studio):**
   - محاكاة دقيقة لقطة القصبة العربية مع التحكم في الزاوية (Angle) والاستدارة (Roundness).
   - معالجة الانسيابية (Streamline / Smoothing) لمنع ارتعاش اليد.
   - دعم كامل للضغط والحساسية (Pressure Sensitivity).

3. **نظام الطبقات المتقدم (Layer Management):**
   - إنشاء، حذف، ترتيب، قفل، وإخفاء الطبقات.
   - ضبط شفافية الطبقة وتصدير الرسوم بدقة فائقة.

4. **ميزان السطور والشبكة الإرشادية (Calligraphy Grid & Rulers):**
   - شبكة سطور تفاعلية لحساب النِّقاط ومطابقة مقاس رأس القلم تلقائياً مع السطر.
   - خط ارتكاز، خط الصعود، وخط الهبوط لضبط ميزان الحروف والكلمات.

5. **محاكي التدريب والكتابة التفاعلية (Trace & Learn):**
   - تتبع مسار الحروف والتدريب الحي على رسم الحركات والاتصالات بالقصبة.

6. **ميزات التطبيق التقدمي (PWA & Offline Ready):**
   - ملف `manifest.webmanifest` لتعريف التطبيق باللغة العربية.
   - مشغّل الخدمة `sw.js` لحفظ الملفات محلياً وتشغيل الاستوديو في أي وقت بدون إنترنت.
   - أيقونات بدقة عالية (192px و 512px) وأيقونات Maskable متوافقة مع Android و iOS و macOS و Windows.
   - زر مدمج للتثبيت بنقرة واحدة كتطبيق مستقل (Standalone App).

## 🚀 التشغيل والتثبيت المحلي (Getting Started)

### 1. التشغيل المباشر:
يمكنك فتح ملف `index.html` في أي متصفح حديث (مثل Chrome، Safari، أو Edge).

### 2. التثبيت كتطبيق مستقل (PWA):
1. قم بتشغيل خادم محلي خفيف (لتفعيل Service Worker):
   ```bash
   npx serve .
   # أو باستخدام بايثون
   python3 -m http.server 8080
   ```
2. افتح الرابط في المتصفح `http://localhost:8080`.
3. اضغط على زر **"تثبيت التطبيق"** الظاهر في الشريط العلوي، أو علامة التثبيت في شريط عنوان المتصفح.

## 🌐 النشر على GitHub Pages

لنشر التطبيق مجاناً عبر GitHub Pages:
1. ارفع المشروع إلى مستودع جديد على GitHub:
   ```bash
   git add .
   git commit -m "feat: initial commit for Procreate Web Studio PWA"
   git branch -M main
   git remote add origin https://github.com/<username>/procreate-web-studio.git
   git push -u origin main
   ```
2. من إعدادات المستودع على GitHub:  
   **Settings > Pages > Branch: main > Save**.
3. سيكون تطبيقك متاحاً ويعمل كـ PWA عبر الرابط المباشر.

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **HTML5 Canvas & JavaScript ES6+** (محرك الرسم ومعالجة المسارات)
* **Tailwind CSS** (تصميم الواجهة المتجاوبة)
* **Service Worker & Cache API** (التخزين المؤقت والعمل دون اتصال)
* **Web App Manifest** (معايير PWA للتثبيت)
* **FontAwesome 6 & Google Fonts (Cairo)** (الخطوط والأيقونات)
